# Commit 约定（可选）

本文件可选。若存在，生成 commit message 时会参考以下约定。

## 前缀

- `feat:` 新功能
- `fix:` 修复
- `refactor:` 重构（不改变行为）
- `i18n:` 国际化/文案
- `style:` 样式、格式（非逻辑）
- `chore:` 构建、配置、杂项
- `docs:` 文档

## 格式

- 标题首行 ≤ 50 字，使用祈使句（如「添加 xxx」而非「添加了 xxx」）。
- 需要时在 body 中列出主要改动点。

## 示例

```
feat: 装修挂件 wgtName 改为 i18n.t() 并补全导入
```
